# Data, tools and generators

Nothing here can be redistributed by this repository unless it says so. Fetch each item from its source and point the environment at it. Copy `scripts/env.example.sh` to `scripts/env.sh`, set the paths, and `source` it. `python scripts/check_data.py` then says what's there and whether it matches the hashes in `manifests/`.

## What each read needs

| Item | Needed for | Variable | In this repository? |
|---|---|---|---|
| FVC B sets, real prints | Almost everything | `FVC_ROOT` | No |
| SFinGe | Every comparison with SFinGe | `FVC_ROOT` | No, it's DB4 of each FVC |
| LEADER model | Everything read by LEADER | `LEADER_ONNX` | No, built by `scripts/export_leader_onnx.py` |
| NIST NBIS (mindtct) | Everything read by mindtct | `RIDGEGEN_TOOLS` | No, built by `scripts/setup.sh` |
| ZP and ZP+P | Most tables | none | Yes, generated from seeds as they're read |
| Turing fronts | Sections 5.10, 5.11 and 6 | `GENERATED_ROOT` | Yes, `scripts/generate/` |
| Anguli | Tables 7 to 10 | `ANGULI_ROOT` | No |
| SynFing | Tables 7 to 10, and the matcher test | `SYNFING_ROOT` | No |
| Diffusion render of ZP | One row of Table 5, and Figures 2 and 3 | `RENDERED_ROOT` | No |
| FVC A sets | The held-out rows of Table 3 | passed as an argument | No, see below |

## FVC B sets

The B sets of FVC2000, FVC2002 and FVC2004, databases 1 to 4: 10 fingers × 8 impressions in each of 12 sets, 960 images. Databases 1 to 3 are real prints from nine sensors. Database 4 of each competition is synthetic, made by SFinGe.

- Source: BioLab, University of Bologna, under Databases at <https://biolab.csr.unibo.it/databasesoftware.asp>.
- Expected layout, with images converted to TIFF where they came as BMP or TIF:

      $FVC_ROOT/FVC2000/DB1_B/101_1.tif
      $FVC_ROOT/FVC2002/DB2_B/101_1.tif
      $FVC_ROOT/FVC2004/DB3_B/110_8.tif

- `manifests/fvc_b.sha256` lists all 960 files.
- Cite Maio et al. 2002a and 2002b and Cappelli et al. 2006. We found no licence stated on BioLab's download pages. Check the terms before publishing anything derived from the images. This repository holds hashes and derived numbers only, and no image.

## FVC A sets, and the held-out protocol

The A sets are in the supplementary material of *Handbook of Fingerprint Recognition*, 3rd edition (Springer). The paper's held-out fingers were read once under `docs/held-out-protocol.md`:

- 30 fingers of each set, the **checking** fingers, were read for Table 3. The list is `results/expected/held_out_checking.json`.
- 70 fingers of each set, the **proving** fingers, remain unread and are meant to stay so until a generator is frozen.

`scripts/reproduce.py` doesn't run these reads. A verifier with their own copy can run `signed_charge.reads.held_out_signed`, which reads only the listed checking fingers. The stored result is `results/expected/held_out_look1.json`.

## LEADER

Cappelli & Ferrara 2026, arXiv:2602.15493, from pyfing (MIT), <https://github.com/raffaele-cappelli/pyfing>. Exported to one ONNX file:

    uv venv /tmp/leader-env --python 3.12
    VIRTUAL_ENV=/tmp/leader-env uv pip install pyfing==0.7.3 keras torch onnx onnxscript onnxruntime scipy
    KERAS_BACKEND=torch /tmp/leader-env/bin/python scripts/export_leader_onnx.py leader.onnx

`manifests/leader.sha256` is the hash of the file used here. An export on another machine may differ in its bytes, so compare outputs if the hash doesn't match.

## NIST NBIS

`scripts/setup.sh` builds NBIS 5.0 from <https://nigos.nist.gov/nist/nbis/nbis_v5_0_0.zip> with mindtct and cjpegl, along with NFIQ 2 and OpenLQM, into `tools/`. It needs gcc, make, curl, unzip and dpkg-deb. Watson et al. 2007, NISTIR 7392.

## ZP and ZP+P

`src/ridgegen` holds the part of ridgegen 0.25.1 these need. Prints are made from seeds as each read runs, and the seeds are in the code, so there's nothing to download.

## Turing fronts

Reimplemented from Glover et al. 2023, and regenerated by `scripts/reproduce.py generate`:

| Set | Script | Prints |
|---|---|---|
| Population, `population_d020` | `scripts/generate/population.sh OUT 120 60 20 4100` | 200 |
| Fronts on model flows, `field_d049` | `scripts/generate/field_population.sh OUT` | 200 |
| Fronts on real flows, `flow_d055` | `scripts/generate/flow_population.sh OUT` | 180 |
| Slower, noisier fronts, `lead_d067` | `scripts/generate/lead_run.sh OUT population 0.5` | 200 |

The fronts laid on real flows use a smoothed version of each finger's orientation field, so treat those prints as derived from FVC images and don't publish them.

## Anguli

Ansari et al., Indian Institute of Science, <https://dsl.cds.iisc.ac.in/projects/Anguli/>. We read the first 90 of the published 1,000-print sample, `1K.tgz`, named `official1k` here. The archive and page state no licence, so it isn't redistributed. Point `ANGULI_ROOT` at the folder holding `1.jpg`, `2.jpg` and so on.

## SynFing

Bouzaglo & Keller 2022, arXiv:2201.06164: 100,000 pairs of GAN-made rolled prints. The paper says code and data are on GitHub, cited as both `rafaelbou/fingerprint-generator` and `rafaelbou/fingerprint_generator`. We found no licence for the dataset itself. Download the five ZIP parts and unpack them as the set's README says, so that `$SYNFING_ROOT/impression_1/F_00000.jpg` exists.

We read first impressions at ids 0, 1111, 2222 and so on: 90 fingerprints, 45 with each artifact type. `scripts/generate/outside_links.sh` makes that selection.

## Diffusion render of ZP

480 prints rendered from ZP's masters by the diffusion pass in `src/ridgegen/diffusion.py`, using IMPOSE (Pan et al., Apache 2.0), with its weights fetched by `src/ridgegen/install_tools.sh --diffusion`. The prints came from a pipeline outside this repository, so they can't yet be regenerated from it. The renders are synthetic and can be shared on request. Without them, `signed_curves` needs `RENDERED_ROOT`, and that one row can't be checked.

## Excluded fingers

`manifests/excluded_fingers.json` lists 18 FVC B fingers kept out of the matcher test, because a separate project uses them as its sealed test set. They're ordinary B fingers and are in every other read.
